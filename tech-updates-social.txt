[6/14/26 8:30 PM] Paschal Chukwu: Wave 1 — Programmatic Agent Integration & API Escrows
1. Automated reveal, transaction building, and settlement endpoints. AI agents can now lease compute programmatically without using a web interface. They submit bids, reveal pricing, build settlement transactions, and complete the settlement cycle fully through the API.
2. X402 Payment Gate. Matched but unpaid orders now respond with an HTTP 402 Payment Required status code, returning the exact USDC price, the target escrow wallet, and a checkout URL. The API only exposes SSH access credentials once the on-chain payment settles, or returns 410 Gone if the lease window expires.
3. Interactive Swagger documentation. The complete OpenAPI specification is served at raw JSON endpoints, and the API documentation route is linked directly from the header. Developers can inspect, test, and integrate the programmatic agent lifecycle end-to-end.
4. Live console metrics. The Agent Console displays real-time rolling spend caps, request counts, and billing data fetched dynamically from the database, giving developers absolute visibility into their agent's active resource usage.
